# ZhiHuiShuHelper

智慧树网课平台掌握度答题助手，采用独立 Python 程序运行。

运行方式：Python + Playwright 驱动独立浏览器，不需要油猴。默认使用本机 Microsoft Edge，浏览器数据单独保存在 `data/browser-profile/`。

已适配常见知识点答题流程：

课程中心 → 知识点答题 → 提交作业 → 掌握度结果 → 查看作答记录与解析 → 重新答题。

## 使用

首次使用需要 Windows、Python 3.10+ 和 Microsoft Edge。先双击 **Install.cmd** 安装依赖，再双击 **Start.cmd** 启动；没有 Edge 时可在界面中选择安装的 Chromium。

1. 首次在图形窗口输入 DeepSeek API Key，输入后会自动加密保存；下次启动自动读取，无需再次输入。设置目标掌握度和运行上限，点击 **开始**。
2. 首次在新打开的浏览器中登录，之后会自动保存并恢复 Cookie。这个浏览器与 GPT 内置浏览器的登录状态独立；平台令登录状态过期或失效时仍需重新登录一次。
3. 进入起始知识点的答题页，脚本自动开始，无需输入课程或章节名称。
   进入后可以最小化脚本打开的浏览器并使用其他窗口；浏览器启用了后台运行设置。保持脚本程序和浏览器打开，需要操作页面或重新登录时再恢复浏览器。
4. 窗口显示课程、章节、知识点、当前题目、轮次、掌握度、完成数量、题库命中、API 请求次数及日志。
5. 使用 **暂停／继续／停止** 控制运行。遇到可恢复错误时，状态显示 **等待重试**，窗口发出提示音并启用 **断点重试**；检查页面或网络后点击即可继续当前步骤。
6. 点击 **初始化** 回到未点击“开始”的状态。程序结束当前任务、保存题库和登录状态、关闭任务浏览器，清空窗口中的进度与日志，恢复“未开始”和可点击的“开始”按钮。API Key、设置、登录数据、题库及历史作答记录保留。初始化完成后等待你再次点击“开始”，不会自动重新运行。

默认勾选“达标后继续下一个知识点”。范围可选“本课程后续知识点”或“仅当前章节”。脚本按课程目录顺序向后处理，跳过已达标及没有掌握度练习的知识点，不会回头重做起始点之前的内容。当前知识点未达标而触及上限时停止，保留日志，不自动跳过失败知识点。

请求次数和时长上限对整次运行有效，不会在切换知识点时重置；最大轮数对每个知识点分别计算。暂停及等待手动重试期间不计入时长，正在进行的网络请求或页面操作会先完成，再暂停或停止。所有实际 API 请求（含格式修正和手动重试）均计入上限。

图形窗口达到 **总请求上限** 时，保留当前题目并等待人工调整，不会自动提高上限。需要继续时，将左侧“总请求上限”改为大于已用次数的总数，点击 **保存设置**，再点击 **断点重试**。例如已用 100 次，把上限改为 150 表示本次总共最多 150 次；原来的 100 次继续计数。只点重试而不提高上限仍会等待，不会发送超出额度的请求。运行中保存设置仅会将总请求上限应用于当前任务，其他设置下次开始生效。

命令行入口保留为 **Start-CLI.cmd**，可在命令窗口按 **Ctrl+C** 停止。

API Key 和 Cookie 分别加密保存在 `data/api-key.dpapi`、`data/browser-cookies.dpapi`，使用 Windows 当前用户的 DPAPI，不写入明文设置。清空 API Key 输入框会删除已保存的 Key。浏览器配置仍保存在固定的 `data/browser-profile/`，保留站点本地存储。

登录状态在运行中定期保存，并在正常关闭浏览器前保存一次；重启时补回有效的会话 Cookie，保留浏览器中已有的新 Cookie，不延长平台设置的有效期。主动退出登录后保存的新状态也会覆盖旧快照。更换 Windows 用户／电脑后，加密文件不能直接复用，需要重新输入 Key 和登录。

脚本从答题网址读取课程 ID 和知识点 ID，再打开同课程的知识学习页，从 DOM 中读取章节 ID、章节名、知识单元和知识点名。补充页面读取完成后会关闭，返回答题页继续。读取失败会停止并说明原因，避免把题目归入错误章节。

迁移到其他电脑时，先安装 Python 3.10+，双击 **Install.cmd** 安装依赖。如果没有 Edge，安装程序会下载 Chromium，此时使用：

```powershell
.\Run.ps1 -Browser chromium
```

也可以指定 Chrome：

```powershell
.\Run.ps1 -Browser chrome
```

## 作答与题库

- 优先使用同课程、同章节中平台确认的正确答案。
- 题目签名包含题干、题型、选项内容和空数，选项顺序改变仍可命中；选项内容不同则重新求解。
- 同一道题在答题页和解析页出现的中文汉字间排版空格统一匹配，例如“测试 选项”与“测试选项”；英文单词间隔、大小写、标点和数学内容保持区分。启动时兼容更新旧题库及作答／解析记录中的签名，合并时优先保留平台确认的答案，再比较更新时间，历史作答不删除。
- 未命中时调用 DeepSeek，验证返回答案和选项是否合法，再填写并回读选中状态。
- 兼容大小写字母、全角字母、逗号分隔／连写的选项字母及能唯一匹配的完整选项文字。仍验证选项范围、重复项及单选数量；无法确认时自动请求一次格式修正，仍失败则等待手动断点重试，不填写猜测答案。
- 提交后读取本知识点的掌握度，采集解析页中本轮全部题目。
- 等待成绩请求结束、总题数加载且掌握度稳定后才记录结果；首次仍为 0% 时，会刷新结果页核对一次，不重复提交答案。合法的 0% 以及与上轮相同的掌握度均可识别。
- 重新答题后等待题干和选项完整加载，再进行识别；解析页同样等待所有题目和参考答案，不把空外框当成完整题目。
- 如果解析仍未覆盖全部已作答题目，日志显示未匹配题干，并允许断点补读；已保存的解析不会因补读重复归档。
- 平台公布的参考答案可以覆盖旧答案；平台判错时撤销旧答案的可信状态。下一次求解会附带该题的错误记录。
- AI 答案未获平台确认前不会作为正确题库答案直接复用。
- 掌握度达到目标后结束当前知识点；勾选自动继续时转入下一个。未达到时从解析页点击“重新答题”，读取新一轮题目，不复用旧试卷 ID。

题库位置：

| 文件 | 内容 |
| --- | --- |
| `data/question-bank.sqlite3` | 原始数据库，保存题目、每次作答和平台反馈 |
| `data/question-bank.json` | 按课程和章节分组的完整导出 |
| `data/chapters/课程ID/章节ID-章节名.json` | 每章单独的题库，附知识点索引 |

公开版不包含任何个人题库、答题记录、登录状态、API Key 或诊断文件。每位使用者的题库从空白开始，数据仅保存在自己的本机。

## 设置

编辑 `profile.json`：

| 设置 | 默认值 |
| --- | --- |
| `target` | 90，掌握度达到 90% 即停止 |
| `max_rounds` | 每个知识点最多 10 轮 |
| `max_api_calls` | 本次运行最多 100 次 API 请求，包含重试，切换知识点不重置 |
| `max_minutes` | 本次运行最多 60 分钟，不包含初次登录等待和暂停时间 |
| `model` | `deepseek-flash` |
| `min_confidence` | 0.6，AI 自报置信度低于此值时显示提示；该数值不是实际正确率 |
| `low_confidence_action` | `continue`：低置信度提示后继续；可改为 `pause` 人工确认或 `stop` 停止 |
| `keep_browser_on_error` | `true`：遇到错误停止时保留浏览器，按回车才关闭 |
| `auto_next` | `true`：达标后继续下一个知识点 |
| `next_scope` | `course`：当前课程后续知识点；`chapter`：仅当前章节 |
| `timeout_seconds` | 页面步骤最多等待 45 秒 |
| `result_settle_seconds` | 成绩数据与相关请求至少稳定 1 秒后读取 |
| `zero_score_grace_seconds` | 0% 数值至少等待 8 秒再核对，避免读取初始占位值 |
| `refresh_zero_result` | `true`：首次 0% 时仅刷新知识点结果页一次，不重复提交 |

实际调用 DeepSeek 需要有效 API Key 和可用额度。请求只发送当前题干、选项和该题历史反馈；不发送登录 Cookie 或整个页面。调用采用官方 [Chat Completions API](https://api-docs.deepseek.com/api/create-chat-completion/) 和 [JSON 输出](https://api-docs.deepseek.com/guides/json_mode/)。

低置信度默认继续使用 AI 建议，建议会保留为“未经平台确认”，不会直接当作正确答案复用。提交后仍按平台的参考答案修正题库。若选择 `pause`，图形窗口会暂停并显示建议，点击“继续”接受建议，点击“停止”结束；命令行模式可按回车继续或输入 `q` 停止。

答案格式、临时网络错误、限流或服务端故障、题目／成绩／解析加载超时以及填写状态回读失败，会保留当前题目、轮次及已经保存的记录，等待点击 **断点重试**。重试只执行失败步骤：AI 失败重新请求当前题，填写失败继续使用已取得的答案，提交后超时只重新等待结果，不重复提交或重复点击已经确认的提交按钮。命令行模式按回车重试，输入 `q` 停止。断点保留在当前运行进程中，关闭程序后不会恢复调用栈。

图形窗口达到请求上限时允许按上述步骤调整后继续；命令行模式仍停止，需修改 `max_api_calls` 后重新运行。达到时间／轮数上限、API 授权错误、切换到其他课程或知识点、定位歧义等问题仍会停止并保留浏览器，避免在无法确认页面状态时继续操作。等待重试时也可点击 **停止** 或 **关闭浏览器**。

**断点重试** 继续当前失败步骤；**初始化** 结束当前运行并恢复待机状态。初始化会等待当前网络请求或页面操作结束，保存记录并关闭任务浏览器，再恢复“开始”按钮。即使当前没有运行任务，点击初始化也只清空窗口进度与日志，不会开始任务。

## 页面诊断

```powershell
.\Run.ps1 -Command check
.\Run.ps1 -Command inspect
.\Run.ps1 -Command export
```

`check` 读取题目与选项，不调用 API、不填写、不提交。`inspect` 将截图、页面框架 HTML 保存到本机 `diagnostics/`，适合网站更新后调整定位。诊断文件可能包含页面中的个人信息，分享前自行检查。

图形窗口和命令行在异常停止时，也会尽可能把当前答题／结果／解析页的截图和 HTML 保存到 `diagnostics/`，日志会显示目录。浏览器继续保留供查看。

运行期间不要手动切换到其他知识点。脚本检测到课程或知识点变化会停止，保留已经保存的数据。

## 已验证范围

已通过模拟页面检查判断题、单选题、题间导航、提交后的页面跳转、掌握度结果、解析展示和重新生成试卷。题库匹配、错误修正、多选、文本输入、完整循环与停止条件通过本地测试验证。

多选题已适配 Element UI 的 `label + checkbox` 控件，支持勾选、取消勾选及原生状态回读。旧版已保存配置也有相应兼容处理。

文本版遇到题干/选项中的图片、画布、无法识别的题型或自定义编辑器会停止。填空题的真实课程控件尚未演示，如其结构与配置不同，需要补充适配。DeepSeek 生成的答案不能保证全对；请求上限可在图形界面中调整，轮数或时长达到上限后会停止。


## 发行包

从 GitHub Releases 下载 Windows ZIP，解压后先运行 `Install.cmd`，再运行 `Start.cmd`。ZIP 不包含 Python 本身，首次安装需要 Python 3.10+ 和网络连接。

维护者可运行 `python tools/package_release.py v1.0.0` 生成只包含运行必需文件的压缩包。推送 `v*` 标签会自动打包并发布对应版本；首次推送到 `main` 会创建 `v1.0.0`。
